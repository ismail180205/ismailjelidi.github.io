Project 01 — OMNI, Intelligent HID Pad

EMBEDDED SYSTEMS / USB / FIRMWARE

PROBLEM

Standard macro pads are fixed-function. The goal: a context-aware input device that adapts to the software in use and understands voice offline.

ARCHITECTURE

Hybrid USB HID + CDC serial. A Python/tkinter companion app auto-detects the device with a PING handshake and stores configuration in NVS flash.

HARDWARE

ESP32-S3 N8R2, 3×3 mechanical switch matrix, rotary encoder, OLED display, analog inputs and an offline voice recognition subsystem.
